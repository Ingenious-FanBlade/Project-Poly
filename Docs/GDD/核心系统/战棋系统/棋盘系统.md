## 1. 设计目的

战棋棋盘系统作为游戏的核心玩法之一，玩家通过打出卡牌来操控我方角色、与敌方角色交互、与中立方交互、与一些棋盘上的地形要素交互

## 2. 目标体验

- 棋盘大小适中，既保证能纵览全局，还要确保不要过小
- 棋盘各方格清晰，有明显交互响应

## 3. 系统边界

### 包含

- 棋盘方格地形类型
- 棋盘方格地形属性
- 棋盘尺寸

## 4. 规则
- 棋盘上的实体均只能在棋盘内存在，也不能移动到棋盘外
- 棋盘上的方格根据其属性，决定其是否能承载实体、与实体的交互。一个方格可以存在多个实体，但只能同时存在一个占据类型的实体。
- 棋盘上的实体会阻挡其他实体的移动，部分地形也会阻挡实体的移动
