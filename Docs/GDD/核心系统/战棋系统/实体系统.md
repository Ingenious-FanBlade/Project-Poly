## 1. 设计目的

战棋棋盘系统作为游戏的核心玩法之一，玩家通过打出卡牌来操控我方角色、与敌方角色交互、与中立方交互、与一些棋盘上的地形要素交互

## 2. 目标体验

- 实体选中标识清晰，实体间交互流畅清晰
- 实体功能属性展示清晰

## 3. 系统边界

### 包含

- 实体类型
- 实体属性

## 4. 规则

- 我方实体中的角色通过打出卡牌与其他实体和地形进行交互，其余的我方实体则能被角色交互
- 敌方实体会有意图显示出来
- 中立实体可以被我方实体和敌方实体交互
- 我方实体和敌方实体都在各自的回合行动，我方实体的具体行动顺序没有限制，敌方实体的则为固定行动顺序
- 敌方实体会显示其每回合的行动意图
