## 1. 设计目的

战棋棋盘系统作为游戏的核心玩法之一，玩家通过打出卡牌来操控我方角色、与敌方角色交互、与中立方交互、与一些棋盘上的地形要素交互

## 4. 规则

- 我方实体中的角色通过打出卡牌与其他实体和地形进行交互，其余的我方实体则能被角色交互
- 敌方角色会有意图显示出来
- 中立实体可以被我方实体和敌方实体交互
- 我方角色和敌方角色都在各自的回合行动，我方角色的具体行动顺序没有限制，敌方角色则为固定行动顺序；敌方非角色实体与中立实体不行动
- 敌方角色的初始固定行动顺序由 `EncounterDefinition` 配置；新增敌方角色统一追加到末尾，已行动实体不重复行动。敌方行动阶段结束前出现的敌方角色参与该回合；敌方回合结束状态触发阶段才出现的敌方角色，下一敌方回合才行动
- 敌方角色会显示其每回合的行动意图
- 敌人意图在我方回合开始前生成。我方每次完整行动（出牌或部署）及连锁稳定后按最新状态刷新；我方回合开始阶段结算稳定后同样刷新。敌方回合中，每个敌方角色开始行动时按最新状态确定实际行动，本回合新增、尚无意图的敌方角色即时决策。具体 AI 算法待敌人意图与 AI 设计细化
- 所有实体的阵营均由实体定义指定，为我方、敌方或中立，在本场战斗中不变化
- 所有实体都有生命与格挡，且都可接收临时型与永久型状态。生命降至 0 时从棋盘移除；生命上限降至 0 时生命随之归零，同样移除；直接移除效果也能不经伤害移除实体。导致其移除的那次效果仍会通知它一次，其状态可借此响应（例如反伤、死亡时触发），之后状态随实体一起清除。我方角色以任一方式移除后都进入复活冷却，冷却结束后可重新部署，规则见[玩家行为和基础准则](../../02_玩家行为与基础规则.md)
- 格挡是实体上独立于状态的数值：受到伤害时先扣格挡，剩余伤害再扣生命，因此伤害数值可以大于实际扣血。伤害不能无视格挡；另有不经格挡、直接扣减生命的生命流失，它与伤害是不同的效果，不会触发只针对伤害的状态（如荆棘）。格挡只在本场战斗有效，不带入下一场
- 格挡在持有者所属阵营的回合结束时清除：我方实体在我方回合结束时、敌方实体在敌方回合结束时清除；中立实体在我方与敌方各完成一个回合后清除。因此我方回合获得的格挡默认不会保留到敌方回合。清除是会通知其他状态的效果，可被“保留格挡”类状态修正而保留部分或全部格挡
- 实体定义可配置初始状态（如精英敌人自带荆棘），实体登场时直接带有，不算一次获得状态的效果；我方角色每次上场都重新带上这些初始状态
- 非占据型实体不占据所在格，也不阻挡其他实体的移动、推动、拉动等位移；同格仍可存在其他实体
- 实体状态分为临时型和永久型：Buff／Debuff 是临时型的典型代表；能力牌施加到实体的能力效果是永久型的典型代表，不按回合到期。所有状态都在战斗结束时清除，不带入下一场战斗
- 获得状态、移除状态和减少层数都是会通知其他状态的效果，可被修正，也可触发连锁；把获得的层数或数值修正为 0 即抵消这次获得，没有数值的能力（如不可重复不可叠加的能力）无法被抵消。回合结束时的自然减层不通知其他状态
- 临时状态的层数同时表示其数值和剩余回合数；同名临时状态的层数相加，例如 3 层再获得 1 层变为 4 层，并持续 4 个对应回合；临时层数与永久能力的数值都不设上限。永久能力的数值可以为负，例如获得 -2 力量。我方和敌方实体的临时状态在所属阵营回合结束时减 1 层，施加当回合也扣减；中立实体在我方与敌方各完成一个回合后减 1 层
- 回合开始／结束事件只由对应回合阵营的状态响应，中立不监听。我方结束时先处理结束状态触发及连锁，再弃牌、清空费用、清除我方格挡，最后扣减我方临时状态；敌方结束状态触发及连锁完成后清除敌方格挡、扣减敌方临时状态，之后清除中立格挡并统一扣减中立临时状态。永久状态不按回合自然衰减，具体时序见[战斗流程与回合状态机](../../../TDD/战斗系统/战斗流程与回合状态机.md)
- 临时状态只要存在，其效果就不受当前回合所属阵营限制；效果通知触发仍须满足持有者的监听资格与状态自身条件。中立实体可持有临时或永久状态，自然衰减仍按上一条规则，但不监听效果执行前、执行后消息。永久状态在任一方回合均可生效
- 永久能力按定义中的重复模式枚举处理：可重复可叠加时合并为一个状态实例并累加数据字段，累加结果为 0 时移除该能力，UI 显示一个能力图标与累计值；可重复不可叠加时每次获得保留独立实例，数值字段不合并，UI 重复显示对应能力图标；不可重复不可叠加时只保留一个实例，数值字段统一为 0，UI 不重复显示图标，也不显示对应数值字段。带内置计数器的能力（如“每消耗 4 点能量获得 1 点”）不会设为可重复可叠加
- 基本出牌条件通过后可在卡牌脚本运行到 `choose()` 时进入可取消的选择；基本条件包括能支付卡牌的基础费用，即使状态可能修正费用，基础费用不足也不能开始出牌尝试。所有可取消选择须在首个卡牌脚本原子效果前完成；取消不扣费、不移动卡牌。完成选择后、首个卡牌脚本原子效果前复验；没有此类效果时在程序正常结束前复验。扣费和卡牌去向分别作为原子效果接受执行前状态修正，经共同验证后一次提交，任一项失败均不发生。提交成功后按扣费、卡牌去向的执行后消息及一次成功出牌消息的顺序发布，三条消息触发的效果在全部发布后结算，再继续卡牌脚本。成功出牌消息与这张牌的目标无关，总是先通知我方、再通知敌方（中立不监听），因此敌人可以响应“玩家打出技能牌”这类事件
- 状态附着于实体，具有监听资格的实体所持状态订阅实际执行的原子效果消息，包括扣费与卡牌去向的原子效果。执行前消息让状态对待结算效果返回修正；抵消效果就是把数值减到 0，仍算该效果已执行；数值修正四舍五入取整，没有硬上限。修正只能改变数值等参数，不能改变效果的目标；“替队友承受伤害”这类能力通过抵消原效果、再对新目标产生新效果实现。结算时目标已不在场的效果则不会生效，也不会让任何状态因它触发，同一张牌的其余效果照常执行；效果按最新战斗状态提交后，执行后消息让状态根据结果触发其他原子效果。两阶段都按相同顺序通知：来源阵营其他在场角色 → 来源阵营其他在场非角色实体 → 来源实体本人 → 对应阵营在场角色 → 对应阵营在场非角色实体，各组按监听序号升序，来源本人只在本人步骤处理；同一实体先处理永久状态、再处理临时状态，各自按获得顺序，状态被清除后再次获得时排到对应类别末尾。效果作用于与来源同阵营的对象时（如治疗队友、给自己加状态），该阵营只按来源方顺序通知一次。本次交互双方中有监听资格的状态均可尝试响应，不限于效果来源与目标；某次效果让实体新获得的状态可响应这次效果本身（如“获得时触发”），被这次效果移除的状态也会最后收到它一次。状态触发的效果默认以持有该状态的实体为来源。状态触发的效果由同一个战斗效果调度器处理：同一条执行后消息先通知完所有监听者，各状态按当时的战斗状态决定是否触发；之后按通知顺序逐个结算触发的效果，每个效果及其引发的连锁结算完才轮到下一个。已触发的效果不因持有者随后被移除而取消。全部连锁完成后才继续原卡牌脚本；出牌事务的三条提交后消息产生的效果须待三条消息全部发布后再结算。“执行 `DamageEffect` 时抽牌”的能力不要求实际扣血大于 `0`。卡牌执行帧只编排脚本，不作为原子效果发布前后消息；成功出牌记录在扣费与卡牌去向都提交后另行发布
- 中立可作为交互的一方阵营，实践中每次只与另一个阵营配对，中立实体不监听效果。无明确来源按没有监听者的虚拟阵营处理，同样与一个对应阵营配对；该分类只用于效果路由，不增加实体阵营类别。多来源、多目标操作生成多个效果按产生顺序依次入队，各效果独立通知和结算，后续效果依据最新战斗状态执行
- 我方与敌方各有一套本场监听序号，决定同组实体接收通知的先后，同一阵营内序号不重复。开战时，我方按出战顺序（玩家可配置）为全部角色编号，冷却中未上场的角色也保留自己的序号；敌方初始实体按遭遇配置的监听顺序编号，与敌方行动顺序相互独立。我方角色复活后重新部署时沿用原序号；召唤物等其他新增实体，接在本阵营已用过的最大序号之后取新号。实体移除后即退出监听（导致其移除的那次效果仍会通知它一次），其序号不再分配给其他实体。中立实体不监听，没有序号
