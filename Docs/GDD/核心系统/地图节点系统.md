## 1. 设计目的

玩家通过在地图上选择节点进入对应的关卡，从而推进游戏进程。

## 2. 目标体验

- 玩家可以直接点击地图上节点的图标进入对应关卡
- 节点之间互相连接，形成一个单起点单终点的图
- 一些特殊节点的数量和位置必须限制

## 3. 系统边界

### 包含
- 节点类型
- 节点构建的地图
- 节点对应的具体关卡

## 4. 规则

1. 玩家不能随意选择节点，必须按照有向图的顺序从前往后一步一步选择。
2. 玩家不能选择和当前节点不相连的下一个节点，也不能再次选择已经探索的节点
3. 玩家只有在完成当前节点之后才能进入下一个节点
