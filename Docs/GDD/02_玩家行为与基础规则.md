## 玩家行为

|玩家行为|输入|前置条件|结果|反馈|
|---|---|---|---|---|
|地图选择节点|鼠标左键|未在战斗或事件中|进入当前节点|动画、音效、转场|
|开始出牌并暂选目标|鼠标左键按住拖动|卡牌在手牌，满足基本出牌条件|进入目标暂选；全部选择完成后显示卡面数值预演，等待最终确认|候选提示、卡面数值预演|
|最终确认出牌|具体输入待定|目标已暂选完成，预演对应当前状态|重新验证并提交出牌，随后结算效果|卡牌效果、动画、音效|
|改选或取消出牌|具体输入待定|出牌尚未最终确认|改选后刷新预演；取消则卡留手牌且不扣费|刷新卡面或退出出牌交互|
|出牌后的选择|具体输入待定|出牌已提交，卡牌效果要求选择|确认即生效，不能取消或改选；没有可选目标时直接跳过|候选提示|
|部署角色|具体输入待定|我方行动阶段，该角色复活冷却已结束，没有进行中的出牌尝试或结算|免费将角色以生命上限部署到任意可进入格|角色登场表现|
|结束我方回合|点击结束回合|我方行动阶段，战斗尚未结束|未提交的出牌尝试先取消；已提交的出牌或部署及其连锁先结算完，再处理结束回合；请求不可撤回|回合状态变化|

## 战斗回合

- 固定我方先手，按我方回合、敌方回合循环。轮次号从 `1` 开始，同一轮双方共用编号，例如我方 `1` → 敌方 `1` → 我方 `2`。
- 我方主动结束回合，不因费用或手牌耗尽自动结束。出牌尚在暂选／最终确认阶段时，先取消尝试再结束回合；出牌已经提交时，等待程序及连锁稳定后再执行结束请求。
- 我方回合开始按复活冷却减 `1` → 费用增加 `4` → 抽 `6` 张 → 回合开始状态触发的顺序处理。开局费用与抽牌就是首个我方回合的这次增加与抽取，不额外重复给予；状态触发及连锁仍可按其规则产生后续变化。
- 我方回合结束按回合结束状态触发 → 弃牌 → 清空费用 → 我方临时状态减层的顺序处理；手牌与费用的保留例外由后续卡牌／状态规则确定。每一步的触发效果与连锁完成后再继续后续步骤。
- 回合开始／结束事件只由对应回合阵营的状态响应；中立不监听。原子效果通知继续按其来源方／对应方规则处理。
- 开战时我方、敌方的初始位置及中立实体的初始位置全部由遭遇配置 `EncounterDefinition` 提供，不进行开局选位；开战上场的我方角色按本局角色顺序（即出战顺序，玩家可配置）依次占用遭遇配置的部署位；该顺序同时决定我方状态的监听先后，规则见[实体系统](核心系统/战棋系统/实体系统.md)。具体费用与牌区规则见[卡牌系统](核心系统/卡牌系统.md)，敌方行动与状态规则见[实体系统](核心系统/战棋系统/实体系统.md)。
- 规则结算不等待动画，但已产生的表现播放完之前不接受玩家的出牌、部署或结束回合操作。

## 生命、资源和失败规则
- 没有全局生命；所有实体都有生命，且都可以接收状态
- 局外资源有金币、角色（棋子）和卡牌，局内资源有棋子血量、牌位（手牌）和费用
- 同一局中，角色的属性与天赋成长跨战斗保留；战后的角色当前生命也延续至后续战斗
- 生命上限变化分永久与临时：永久变化跨战斗保留；临时变化只在本场战斗、只对当前上场的角色有效，角色死亡或战斗结束即失效，战后当前生命不超过永久的生命上限。生命上限降至 0 时角色按死亡处理；永久降低使生命上限低于 1 时，之后重新部署与战后保留的生命上限按 1 计
- 我方角色在战斗中死亡后进入 `3` 个我方回合的复活冷却，冷却跨战斗保存，非战斗节点不影响冷却。冷却只在我方回合开始时减 `1`，减到 `0` 的那个我方回合即可部署，例如在我方或敌方第 `2` 回合死亡的角色都在我方第 `5` 回合可部署
- 冷却结束的角色可在我方行动阶段免费部署到任意可进入格，每个角色部署一次，以生命上限上场。新战斗开始时，冷却已结束的角色自动上场（此前死亡的以生命上限上场），冷却中的角色不上场，冷却结束后再手动部署
- 战斗中场上没有我方角色（我方角色全部死亡）时游戏失败；冷却中或待部署的角色不能挽回
- 胜败在当前行动程序、原子效果及其连锁稳定后判定；同一次稳定结算后，我方角色全灭与敌方角色全灭同时成立时判失败

## 胜利及关卡结束条件
- 击败最终boss即宣告游戏胜利
- 击败关卡内所有敌方角色时即宣告该战斗关卡结束；敌方非角色实体与中立实体是否存活不影响
- 完成事件抉择即宣告该事件关卡结束
